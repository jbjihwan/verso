# VERSO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 양면 카드(사용 시 뒤집힘) 타로 로그라이트 덱빌딩 VERSO 를 웹(PC+모바일)용으로 완성해 GitHub Pages 에 배포한다.

**Architecture:** DOM 을 모르는 순수 로직(`src/core`)이 JSON 직렬화 가능한 상태를 동기적으로 바꾸고 이벤트 로그를 돌려준다.
UI(`src/ui`)는 이벤트를 순서대로 연출한 뒤 상태에서 화면을 다시 그린다. 콘텐츠(카드·적·유물·이벤트)는 `src/core/data` 의 데이터+함수로 정의한다.

**Tech Stack:** 바닐라 JS(ES 모듈) · DOM/CSS · 인라인 SVG · WebAudio · `node --test`(작성만) · Python 개발 서버 · GitHub Pages

**Spec:** `docs/superpowers/specs/2026-09-11-verso-design.md`

## Global Constraints

- 런타임 의존성 0 · 에셋 파일 0 · 외부 요청 0 · 빌드 단계 없음(브라우저가 `index.html` 을 바로 연다)
- `src/core/**` 는 `document`/`window` 를 참조하지 않는다(Node 에서 import 가능해야 함)
- 게임플레이 난수는 `src/core/rng.js` 스트림에서만. `Math.random` 은 UI 장식에만
- 모든 플레이어 대면 문자열은 `{ ko, en }` 두 벌. 기본 언어는 `navigator.language` 가 `ko*` 면 `ko`, 아니면 `en`
- 저장 키: `verso:settings:v1`, `verso:meta:v1`, `verso:run:v1`, 격리 키 `verso:run:corrupt`
- 스테이지: 가로형 높이 720·너비 clamp(aspect×720, 1024, 1560) / 세로형(aspect<0.9) 너비 720·높이 clamp(720/aspect, 1080, 1600)
- 기본 수치: 에너지 3 · 드로우 5 · 무료 뒤집기 1/턴 · 손패 10 · 물약 슬롯 3 · 시작 골드 99 · 바보 HP 72 · 마법사 HP 64
- **테스트는 사용자가 지시할 때만 실행한다.** 각 태스크의 테스트는 작성하되 실행 단계는 "브라우저 검증"으로 대체
- 커밋: 태스크마다. 메시지 끝에 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` 와 `Claude-Session:` 줄

## 이 계획의 형식에 대한 메모

게임 전체(수만 줄 규모)를 계획서에 코드로 옮기면 같은 코드를 두 번 쓰게 된다. 사용자가 자율 진행을 지시했고
토큰 비용에 민감하므로, 이 계획은 **파일 구조 · 모듈 간 계약(정확한 이름·시그니처·데이터 형태) · 태스크 순서 ·
검증 방법**을 확정하는 수준으로 쓴다. 콘텐츠의 세부 수치(카드 효과 숫자 등)는 스펙의 규칙과 수량 안에서 구현 시 설계한다.
실행은 **executing-plans 인라인** — 사용자 지시 없이 서브에이전트를 띄우지 않는다.

## 핵심 계약

### rng.js

```js
export function hashSeed(str)            // → uint32 (xmur3 계열)
export function makeRng(seed)            // → { s: uint32 }  (순수 데이터)
export function next(r)                  // → [0,1)  r.s 를 갱신 (mulberry32)
export function int(r, lo, hi)           // → lo..hi 정수(양끝 포함)
export function pick(r, arr)
export function shuffle(r, arr)          // 제자리 Fisher–Yates, arr 반환
export function chance(r, p)             // p ∈ [0,1]
export function weighted(r, pairs)       // pairs: [[item, weight], ...] → item
export function streams(seed)            // → { map, reward, combat, event, shop, misc } 각각 makeRng(hashSeed(`${seed}:${name}`))
```

### 카드 정의와 인스턴스 (cards.js)

```js
// 정의
{ id, pool: 'basic'|'fool'|'magician'|'neutral'|'curse'|'status', rarity: 'basic'|'common'|'uncommon'|'rare'|'special',
  art: 'sword' | ['sun','sword'], lock: 'A'|'B'|undefined,
  onFlip: { vals, upg, text:{ko,en}, run(ctx, v) } | undefined,
  faces: [Face, Face] }
// Face
{ name:{ko,en}, type:'attack'|'skill'|'power'|'curse'|'status', cost: number|'X'|null,
  upgCost?: number, target:'enemy'|'all'|'self'|'none',
  vals:{...}, upg:{...}, kw:['vanish'|'retain'|'steady'|'innate'|'ethereal'|'unplayable'],
  text:{ ko:(v)=>string, en:(v)=>string },
  play(ctx, v), resume?: { [key]: (ctx, v, picked /* inst[] */) => void },
  canPlay?(cs) → boolean }
// 인스턴스(덱·전투 더미에 들어가는 순수 데이터)
{ uid: 'c17', id: 'strike', up: 0|1, rev: false, swapped: false,
  /* 전투 한정 */ costMod?: number, stuck?: boolean }

export function registerCards(list)
export function cardDef(id)
export function allCards()                         // 정의 배열
export function makeInst(run, id, { up=0, rev=false } = {})   // run.uid 카운터 사용
export function faceIdx(inst)                      // inst.rev ? 1 : 0
export function faceOf(inst)                       // cardDef(inst.id).faces[faceIdx(inst)]
export function valsOf(inst, fi = faceIdx(inst))   // up 이면 {...vals, ...upg}
export function costOf(inst, fi = faceIdx(inst))   // upgCost·costMod 반영, 'X'/null 그대로
export function hasKw(inst, kw, fi = faceIdx(inst))
export function cardName(inst, fi)                 // 강화 시 '+'
```

값 키 규칙: 이름이 `dmg` 로 시작하면 공격 보정, `blk` 로 시작하면 방어도 보정 대상(표시값 계산에 사용).
