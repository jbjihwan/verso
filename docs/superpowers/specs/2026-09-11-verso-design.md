## 1. 한 줄 요약

> **Every card has two faces. Every play turns it over.**
> 모든 카드에는 두 얼굴이 있고, 쓸 때마다 뒤집힌다.

타로 테마의 턴제 로그라이트 덱빌딩. 모든 카드는 **정방향(Upright)** 과 **역방향(Reversed)** 두 면을 가진다.
카드의 위쪽 절반이 현재 면이고, 아래쪽 절반에는 반대 면이 거꾸로 인쇄되어 있다(실제 타로 카드처럼).
카드를 사용하면 현재 면의 효과가 발동한 뒤 카드가 **180° 회전해 뒤집힌 채로** 버린 더미로 간다.
덱 전체의 방향 상태가 계속 바뀌므로, "다음에 어느 면이 올라올지"를 설계하는 것이 핵심 퍼즐이다.

## 2. 접근 방식 결정

| 안 | 내용 | 판단 |
|---|---|---|
| **A. 턴제 덱빌딩 + 양면 카드 (채택)** | 슬레이 더 스파이어류 구조(맵·전투·보상) 위에 "양면 카드·사용 시 뒤집힘" 규칙 | 전략 깊이 대비 구현 효율이 가장 좋고, 탭 기반이라 모바일에 자연스럽다. 양면 규칙이 "클론이 아닌 독창성"을 준다 |
| B. 카드로 유닛을 까는 레인 디펜스 | 적이 레인을 따라 전진, 카드로 배치 | 독창적이지만 실시간·위치 요소가 모바일 조작과 밸런스를 크게 어렵게 한다 |
| C. 순수 타워 디펜스 | 경로·타워 배치 | "카드" 요소가 약해 선택한 장르 의도와 멀다 |

렌더링은 **DOM + CSS + 인라인 SVG** 를 택한다(Coreward 는 Canvas 였음).
카드 게임은 텍스트가 많고(한/영 2개 언어), 뒤집기 연출이 CSS transform 한 줄로 해결되며, 레이아웃이 문서 흐름에 잘 맞는다.
파티클 같은 순수 이펙트만 전체 화면 위 `<canvas>` 오버레이로 그린다.

## 3. 기술 원칙

- 바닐라 JavaScript(ES 모듈) · 빌드/번들러/트랜스파일러 없음 · **런타임 의존성 0 · 에셋 파일 0 · 외부 요청 0**
  - 그림은 전부 코드로 그린 SVG, 소리는 전부 WebAudio 합성, 폰트는 시스템 폰트 스택
- 게임 로직(`src/core/`)은 **DOM 을 모르는 순수 모듈** — Node 에서 그대로 import 해 테스트 가능
- 모든 게임플레이 난수는 **시드 기반 RNG 스트림**에서만 뽑는다(UI 의 장식용 난수만 `Math.random`)
- 게임 상태는 **JSON 직렬화 가능한 순수 데이터** — 전투 도중에도 매 행동마다 자동 저장
- 언어: **한국어 / English** 두 벌. 브라우저 언어가 `ko*` 면 한국어, 아니면 영어로 시작하고 설정에서 전환

## 4. 전투 규칙

### 4.1 턴 흐름

1. **플레이어 턴 시작**: 방어도 0 으로 초기화(보루 효과 예외) → 에너지 = 최대 에너지(기본 3) →
   뒤집기 = 1 회 → 카드 5장 드로우 → 턴 시작 상태이상 처리(독 등)
   (구현 중 변경: 실제 순서는 턴 시작 상태이상 → 드로우다. 독으로 쓰러지면 드로우가 의미 없고
   결과도 같아 엔진을 그대로 두었다. `startPlayerTurn` 참고)
2. **플레이어 행동**(순서 자유): 카드 사용 · 손패 카드 뒤집기(뒤집기 1 소모) · 물약 사용 · 카드 살펴보기
3. **턴 종료**: 턴 종료 효과(재생, 파워 등) → 손패 버리기(보존 카드 제외, 방향은 그대로 유지) →
   플레이어의 지속형 디버프(취약·약화·허약) 1 감소
4. **적 턴**: 적마다 순서대로 방어도 0 → 독 처리 → 예고했던 행동 실행 → 지속형 디버프 1 감소 →
   모든 적이 끝나면 다음 행동(의도)을 결정해 머리 위에 표시

### 4.2 카드 사용 순서

비용 지불 → 카드가 "해결 중" 영역으로 → **현재 면의 효과 해결** → (선택이 필요하면 선택 대기) →
**카드 뒤집기**(고정 키워드면 생략, 뒤집힐 때 효과 발동) → 카드 사용 훅(유물·파워) →
목적지로 이동: 파워면 전투에서 제거(효과는 지속), 소멸이면 소멸 더미, 그 외 버린 더미

### 4.3 뒤집기 규칙

- 카드 인스턴스는 방향 `rev`(false=정방향, true=역방향)를 가진다. **전투 시작 시 모두 정방향**으로 초기화
  (이벤트 "두 얼굴의 상인"으로 면을 영구 교환한 카드는 역방향으로 시작)
- **무료 뒤집기**: 턴마다 1회. 이월되지 않는다. 유물·카드로 추가 획득 가능
- 카드마다 면별로 **이름·비용·유형·효과가 다를 수 있다** (예: 정방향 공격 / 역방향 스킬)
- **뒤집힐 때(On Flip)** 효과: 어떤 이유로든(사용·수동·효과) 뒤집힐 때 발동. 두 면 텍스트 모두에 적는다
- **무한 루프 방지**: "뒤집힐 때" 효과를 해결하는 도중 일어난 뒤집기는 다시 "뒤집힐 때"를 발동하지 않는다
- 면 설계 원칙: 정방향 = 안정적·기본기, 역방향 = 날카로움(더 강하지만 대가) 또는 **다른 역할**.
  한쪽이 단순 상위호환이 되지 않게 한다

### 4.5 수치 공식

- 공격 피해(타격당) = `max(0, floor((기본값 + 공격자 힘) × (공격자 약화 ? 0.75 : 1) × (대상 취약 ? 1.5 : 1)))`
- 카드 방어도 = `max(0, floor((기본값 + 민첩) × (허약 ? 0.75 : 1)))`
- 피해는 방어도가 먼저 흡수. **체력 손실**(독, 자해 등)은 방어도를 무시
- 카드·의도에 표시되는 숫자는 위 보정을 반영한 **실제 값**(보정으로 달라지면 색으로 표시)

마법사의 "정방향=충전 / 역방향=방출" 구조는 핵심 규칙(사용하면 뒤집힘)을 그대로 캐릭터 정체성으로 삼는다.

공용 시작 카드 예시:
- **타격 / 잽**: 정 `1 · 피해 6`(강화 9) · 역 `0 · 피해 3`(강화 5)
- **방어 / 버티기**: 정 `1 · 방어도 5`(강화 8) · 역 `0 · 방어도 3`(강화 5)

## 7. 세계와 적

| 막 | 이름 | 수트·색 | 일반 적 | 정예 | 보스(런마다 1명 무작위) |
|---|---|---|---|---|---|
| I | 잿불 황야 The Ember Wilds | 완드 · 잿불 주황/숯 | 불씨 도깨비, 횃불지기, 불쏘시개 풍뎅이, 재 도깨비불, 가시덤불이 | 완드의 기사, 완드의 여왕 | **전차(VII)** · **은둔자(IX)** |
| II | 가라앉은 궁정 The Drowned Court | 컵 · 청록/남색 | 소금물 장어, 성배 미믹, 조수 망령, 산호 병졸, 칠성장어 떼 | 컵의 기사, 컵의 여왕 | **매달린 사람(XII)** · **여사제(II)** |
| III | 유리 성채 The Glass Citadel | 소드 · 은/보라 | 칼춤꾼, 돌풍 매, 거울 파수꾼, 파편 골렘, 맹세파기자 | 소드의 기사, 소드의 왕 | **탑(XVI)** · **정의(XI)** |

- **적도 카드다**: 일부 적은 정/역 **자세(stance)** 가 있어, 조건에 따라 뒤집히며 행동 패턴이 바뀐다
- 보스 핵심 기믹(한 줄):
  - 전차 — 기어를 올려(힘·방어) 돌진, 체력 절반에서 역방향 "폭주 전차"로 뒤집혀 방어를 버리고 몰아친다
  - 은둔자 — 방어도가 사라지지 않는(보루) 느린 보스, 등불로 현기증 카드를 섞는다 — 화력 경쟁
  - 매달린 사람 — **도치**: 플레이어 턴 시작마다 손패 전체가 뒤집힌다
  - 여사제 — 매 턴 정/역 자세를 번갈아(정: 가시·방어 / 역: 강공) — 때릴 타이밍을 고르는 싸움
  - 탑 — 체력 2/3·1/3 에서 **붕괴**: 잔해 카드를 덱에 섞고 힘 증가
  - 정의 — **저울**: 한 턴에 준 피해와 얻은 방어도의 불균형을 벌한다(UI 에 저울 표시)
- 적 의도 아이콘: 공격(수치·타수) · 방어 · 버프 · 디버프 · 소환 · 알 수 없음

## 8. 런 구조와 맵

- 3막 × (8층 + 보스). 3막 보스 처치 = 승리
- 맵 생성(막마다): 6열 × 8행 격자에 경로 4개를 아래→위로 생성. 한 걸음은 열 −1/0/+1, **기존 간선과 교차 금지**
  - 0행 = 전투, 3행 = 보물, 7행 = 휴식(성소) 고정
  - 나머지: 전투 45 · 이벤트 22 · 정예 12(2행부터) · 휴식 12(4~5행만) · 상점 9(2행부터)
  - 같은 경로에서 정예·휴식·상점이 연달아 나오지 않게 다시 뽑는다
  - 7행 전 노드가 보스로 연결
- 막 전환: 보스 처치 → 보스 유물 3개 중 1개 → 잃은 체력의 75% 회복 → 다음 막 맵
- 노드 종류: 전투 · 정예 · 이벤트(?) · 상점 · 성소(휴식) · 보물 · 보스

## 9. 보상·상점·성소·이벤트

- **전투 보상**: 골드(1막 10–20, 2막 15–25, 3막 20–30) · 카드 3장 중 1장(건너뛰기 가능) · 물약(40% 시작, 드롭 시 −10%p, 미드롭 시 +10%p)
  - 희귀도 가중치 — 일반전 60/35/5 · 정예 45/42/13 · 보스는 희귀만. 2막 10%·3막 20% 확률로 이미 강화된 카드
- **정예**: 골드 ×2 + 유물 1 + 카드 보상(정예 가중치)
- **보스**: 골드 90–110 + 희귀 카드 보상 + 보스 유물 선택
- **상점**: 캐릭터 카드 5(일반 45–55 · 고급 70–80 · 희귀 140–160, 하나는 반값) · 무색 2 · 유물 3 · 물약 3 · 카드 제거(75, 사용할 때마다 +25). 가격 ±10% 변동
- **성소(휴식)**: 휴식(최대 체력 30% 회복) 또는 정련(카드 1장 강화). 일부 유물이 선택지를 추가
- **이벤트 12종**(막 태그 있음): 운명의 수레바퀴, 두 얼굴의 상인(카드 면 영구 교환), 거울 연못(카드 복제), 잿불 사당,
  가라앉은 종, 연인, 방랑 은자, 도박판, 절제의 샘, 부서진 석상(정예전 선택), 별자리표, 가면 극단(카드 변환)

## 10. 메타 진행과 저장

- **통찰(Insight)**: 런 종료 시 획득 = 층×5 + 정예×15 + 보스×50 + 승리 100, 징조 단계마다 +10%
- **아르카나 레벨** 1–7(누적 통찰 0/100/250/450/700/1000/1400):
  L2 바보 카드 A · L3 유물 A · L4 마법사 카드 A · L5 바보 카드 B · L6 유물 B · L7 마법사 카드 B (각 3개)
- **징조(난이도)**: 캐릭터별로 현재 단계를 이기면 다음 단계 해금, 효과 누적
  1 일반 적 체력 +10% · 2 정예·보스가 힘 1로 시작 · 3 휴식 회복 20% · 4 저주 "의심"을 들고 시작 · 5 보스 체력 +20%
- **도감**: 카드·유물 목록(해금 안 된 것은 실루엣) · **기록**: 캐릭터별 판수·승리·최고 층
- **저장**(localStorage, 버전 봉투 `{v, data}`): `verso:settings:v1`, `verso:meta:v1`, `verso:run:v1`
  - 런은 **매 행동마다** 자동 저장(전투 포함). 난수 스트림 상태도 저장하므로 새로고침으로 결과를 다시 뽑을 수 없다
  - 읽기 실패 시 원본을 `verso:run:corrupt` 로 **격리**하고 알린다 — 조용히 지우지 않는다(Coreward 2단계 교훈)

## 11. 화면과 조작

### 11.1 스테이지 스케일링

- 고정 크기 논리 스테이지를 `transform: scale()` 로 화면에 맞춘다. **짧은 변 고정, 긴 변 가변**
  - 가로형: 높이 720, 너비 = clamp(화면비×720, 1024, 1560)
  - 세로형(화면 너비/높이 < 0.9): 너비 560, 높이 = clamp(560/화면비, 860, 1240)
    (구현 중 변경: 처음 정한 720은 390px 폭 휴대폰에서 0.54배로 줄어 카드 글씨가 7px 수준이었다)
- 레이아웃은 `.landscape` / `.portrait` 두 벌의 CSS 로 나눈다. 남는 여백은 막 배경색으로 채운다

### 11.2 화면 목록

타이틀 · 캐릭터 선택(징조 선택 포함) · 맵 · 전투 · 보상 · 상점 · 성소 · 이벤트 · 보물 · 보스 유물 · 결과(패배/승리, 통찰·해금 알림) ·
덱 보기(오버레이) · 도감 · 설정. 런 중에는 상단 바(체력·골드·막/층·물약·유물·덱)가 항상 보인다.

### 11.3 카드 디자인

```
┌─────────────────────────┐
│ ① 타격            ⚔    │ ← 현재 면: 비용 · 면 이름 · 유형
│  피해 6               │ ← 현재 면 효과
│        ( 문장 )         │ ← 가운데 원형 삽화(점대칭)
│               3 해피  │ ← 반대 면 효과(거꾸로, 흐리게)
│    ⚔            잽 ⓪ │ ← 반대 면 헤더(거꾸로)
└─────────────────────────┘
```

- 카드는 **실제로 점대칭**이다: 정방향 면 절반과, 180° 돌린 역방향 면 절반. 뒤집기는 카드 전체를 180° 회전시키는 CSS 전이
- 유형 색: 공격 주홍 · 스킬 청록 · 파워 보라 · 저주 검정 · 상태 회색. 희귀도: 일반 잉크 테두리 · 고급 은선 · 희귀 금박(은은한 광택)
- 확대 보기(길게 누르기/우클릭/호버)에서는 두 면을 **나란히 똑바로** 보여 주고 키워드 설명을 붙인다

### 11.4 조작

- **탭/클릭**: 카드 선택 → (대상 필요) 적 탭 · (대상 불필요) 같은 카드 다시 탭 또는 위로 끌기
- **드래그**: 카드를 끌어 적 위(또는 전장 위)에 놓기
- 선택한 카드 옆 **↻ 버튼**으로 무료 뒤집기. 길게 누르기 = 확대 보기. 빈 곳 탭 = 선택 해제
- 키보드: `1`–`0` 카드 선택 · `F` 뒤집기 · `←/→` 대상 변경 · `Enter`/`Space` 사용 · `E` 턴 종료 · `Esc` 취소
- 첫 전투에서 한 번만 보이는 짧은 안내(카드 사용, 뒤집기, 적 의도, 턴 종료)

### 11.5 아트·연출

- 배경: 막별 그라데이션 + SVG 문양(잿불 / 물방울 / 유리 파편)이 천천히 흐른다
- 적·캐릭터·카드 삽화: 도형 조합으로 만든 **SVG 라인아트**(잉크 + 금선), 적마다 실루엣이 다르고 숨쉬기 애니메이션
- 대표 연출: 카드가 대상에게 날아가며 **공중에서 180° 회전**해 버린 더미로 빨려 들어간다
- 피격 번쩍임·흔들림·떠오르는 숫자·방어도 깨짐·보스 등장 연출. 설정에 **빠른 연출**·**화면 흔들림** 토글

### 13.1 전투 엔진 계약

- 행동: `playCard(cs, uid, targetId)` · `flipCard(cs, uid)` · `usePotion(cs, slot, targetId)` · `choose(cs, selection)` · `endTurn(cs)`
- 각 행동은 상태를 **동기적으로** 변경하고 이벤트 배열을 반환한다
  (`draw`, `play`, `flip`, `damage{amount, hpAfter, blockAfter}`, `block`, `status{stacks}`, `heal`, `energy`, `enemyMove`, `intent`, `death`, `shuffle`, `victory`, `defeat` …)
- UI 는 이벤트를 순서대로 **연출만** 하고, 끝나면 상태에서 전체를 다시 그린다 → 연출이 로직을 오염시키지 않는다
- 선택이 필요한 효과는 `cs.pending = {kind, spec, cardUid, key}` 를 세우고 멈춘다. UI 가 `choose()` 로 재개. 문자열 키만 저장하므로 직렬화 가능
- 훅 순서: 유물 → 파워/상태이상. 훅 이름: `combatStart, turnStart, turnEnd, cardPlayed, flip, attacked, hpLost, blockGained, enemyDied, shuffle, victory`

### 13.2 데이터 형태(카드)

```js
{
  id: 'strike', type: 'attack', rarity: 'basic', art: 'sword',
  faces: [
    { name: { ko: '타격', en: 'Strike' }, cost: 1, target: 'enemy',
      vals: { dmg: 6 }, upg: { dmg: 9 },
      text: { ko: v => `피해 ${v.dmg}`, en: v => `Deal ${v.dmg} damage.` },
      play: (ctx, v) => ctx.attack(ctx.target, v.dmg) },
    { name: { ko: '잽', en: 'Jab' }, cost: 0, target: 'enemy',
      vals: { dmg: 3 }, upg: { dmg: 5 }, ... }
  ],
  keywords: [], onFlip: null
}
```

값 키 규칙: `dmg*` 는 공격 보정, `blk*` 는 방어도 보정을 받아 **표시값이 자동 계산**된다.
